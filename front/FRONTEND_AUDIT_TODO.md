# Фронт и бэк: остаток доводки (от 29.09.2026)

Цель пользователя — платформа, оптимальная по пяти осям: **трафик, скорость и
быстродействие, нагрузка на устройство (CPU, GPU, батарея, особенно в простое),
расход памяти, безопасность**. Сделанное удалять из файла вместе с правкой.

## Правила работы (обязательно)

- После каждой правки фронта: `npm run lint` → 0 ошибок и 0 предупреждений,
  находки только ИСПРАВЛЯТЬ; `npx vitest run --project unit` — зелёный;
  сборка `npx vite build` во временный `outDir`.
- Новое поведение — с юнит-тестом.
- Зависимости ставить ТОЛЬКО в linux-контейнере (`--package-lock-only` в
  `node:24-alpine`, затем локально `npm ci`).
- Браузер самому не запускать — проверяет пользователь (см. «Как проверить»).
- Не коммитить и не деплоить без явной команды. Работа — в `develop`.

## 1. CSP: из Report-Only — в действие

Заголовки лежат в `deploy/nginx/snippets/security_headers.conf` (подключён в
оба конфига nginx). CSP пока `Content-Security-Policy-Report-Only`. Порядок:
выкатить, пройти сценарии из «Как проверить», п.6, собрать нарушения из
консоли, поправить источники и только потом переименовать заголовок в
`Content-Security-Policy`. Выкат nginx — с `--force-recreate` (новый том
`snippets`, см. CLAUDE.md «Деплой»).

## 2. vitest 2 → 4

`npm audit` (только dev-зависимости): moderate в `vitest`/`@vitest/mocker`
(чтение файлов через redirect-мок) — затрагивает лишь запуск тестов, в продукт
не попадает. Исправлено в мажорной версии; обновлять вместе с конфигом
проектов `unit`/`integration`.

## 3. Как проверить (просить пользователя)

0. Заметки (TipTap 3): набор и форматирование, ссылки, подчёркивание,
   таблицы, чек-листы, картинки с ресайзом, совместная правка в двух окнах,
   ИИ-правка, экспорт docx, публичная ссылка на чтение и на правку. Открытие
   старой заметки не должно помечать её изменённой.

1. Chrome DevTools → Performance monitor в простое 5 минут на столе и на
   «Виджетах»: CPU %, JS event listeners, DOM nodes, JS heap.
2. Memory → heap snapshot после часа работы (открыть/закрыть 20 чатов, окна).
3. Network в простое 10 минут: число запросов и кадров WS (живые плитки
   теперь перезапрашиваются по событиям раздела, а не раз в минуту).
4. Мессенджер (лента виртуальная): длинный чат — прокрутка вверх с догрузкой
   истории, переход к цитате и к закреплённому, «к последним», клик по дате,
   ресайз окна, картинки в ленте, клавиатура на телефоне.
5. Портал (лента виртуальная) и канбан задач (колонки виртуальные):
   «Показать ещё», раскрытие комментариев, перетаскивание карточки между
   колонками, в том числе с прокруткой колонки.
6. После выката: securityheaders.com по прод-домену; консоль без нарушений CSP
   на десктопе, телефоне (обёртка), в звонке, при загрузке файлов и с Метрикой.
7. «Настройки → Темы и оформление → Меньше прозрачности»: стекло исчезает,
   нагрузка GPU в простое падает.
8. Телефон (обёртка): расход батареи приложением за ночь в фоне.
