## 1. Безопасность

### 1.1 Заголовки безопасности в nginx (ВЫСОКИЙ)
В `deploy/nginx/nginx.prod.conf` нет ни одного: ни CSP, ни HSTS, ни защиты от
фреймов. Добавить на серверный блок приложения (и сверить с
`deploy/nginx/nginx.conf` — конфигов ДВА, см. CLAUDE.md «Деплой»):
- `Strict-Transport-Security: max-age=31536000; includeSubDomains`
- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Content-Security-Policy` с `frame-ancestors 'self'` (защита от
  кликджекинга; `X-Frame-Options: SAMEORIGIN` — для старых браузеров).
  Остальные директивы CSP собрать по факту: `script-src 'self'` (+ Яндекс.
  Метрика, id 110869595), `connect-src 'self' wss:` + LiveKit, `img-src 'self'
  data: blob:` + S3-бакет, `media-src`, `worker-src 'self'` (sw.js),
  `style-src 'self' 'unsafe-inline'` (Vue scoped + инлайн-стили PrimeVue).
  Сначала выкатить как `Content-Security-Policy-Report-Only`, собрать
  нарушения, потом включить. Проверить обёртки: Electron и Capacitor грузят
  тот же прод-URL.
- `Permissions-Policy`: камера/микрофон/экран — только `self` (звонки).
Всё с `always`, чтобы заголовки были и на ошибках. Помнить про грабли
bind-mount конфига nginx (`--force-recreate`).

## 3. Скорость и быстродействие

### 3.1 Виртуализация длинных списков
Лента сообщений (`views/MessengerView.vue`), список задач, лента портала,
записи реестров — все элементы в DOM. Минимум — `content-visibility: auto` +
`contain-intrinsic-size` на элементах, которые вне экрана (для ленты
сообщений осторожно: прокрутка к низу и сохранение позиции при догрузке
истории — проверить `onScroll`/`useJumpToMessage`). Полноценная виртуализация
— отдельным решением с пользователем.

### 3.2 Стекло
`blur(28px) saturate(1.7)` на каждом окне (`AppWindow`) и вложенной панели
`AppPage` + панели каркаса. Вложенное стекло внутри окна — лишний проход
(backdrop root). Сделать:
- `AppPage` внутри окна без собственного `backdrop-filter` (окно уже стекло);
- настройка «Меньше прозрачности» + автоматически при
  `prefers-reduced-transparency: reduce`: плотные подложки вместо blur
  (токены в `assets/tokens.css`, переключатель — атрибут на корне).

### 3.3 `MarkdownView`
Теперь разбирает HTML через `<template>` на каждое изменение текста. В ленте
сообщений это на каждый пузырь при монтировании — замерить; при нужде
кэшировать дерево VNode по строке источника (Map с ограничением размера).

### 3.4 Сокет Android-обёртки в фоне (смежное, бэкенд п.5)

Сессия не запускает браузер — нужны замеры пользователя «до/после»:
1. Chrome DevTools → Performance monitor в простое 5 минут на столе и на

2. Memory → heap snapshot после часа работы (открыть/закрыть 20 чатов, окна).
3. Network в простое 10 минут: число запросов и кадров WS.
4. Мессенджер: ресайз окна и быстрое переключение чатов — нет ли фризов.
5. Телефон (обёртка): расход батареи приложением за ночь в фоне.
6. После 1.1: securityheaders.com по прод-домену и отсутствие нарушений CSP в
   консоли (десктоп, телефон, звонок, загрузка файлов, Метрика).
